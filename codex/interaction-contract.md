# Codex 原生互动边界

以下结论在 2026-11-01 根据本机 Codex 26.1021.31345 的打包代码核对。这里只替换自定义宠物素材，不修改客户端本体。

| 操作或状态 | 客户端行为 | 素材可控制的部分 |
|---|---|---|
| 待机 | 播放 `idle` 六帧 | 每帧的表情、站姿、压缩拉伸 |
| 鼠标进入角色 | 临时触发 `jumping` 五帧 | 可设计成碰到角色后的表情回应 |
| 拖动超过约 4 个屏幕点 | 播放左右移动行并移动窗口 | 可保持站姿，叠加固定脚底的弹性变化 |
| 单击且未拖动 | 打开、聚焦主窗口 | 不能通过素材改成轮换表情 |
| 右键 | Settings / Close Mini | 不能在素材里添加表情菜单 |
| 工作、等待、审阅、失败 | 由宿主选择相应动画行 | 每一行的立绘及逐帧效果 |

`pet.json` 只有身份、名称、描述、图片路径及图集版本字段，没有点击回调、脚本、随机计时器、漫游半径或速度字段。随机窗口游走和点击轮换表情需要客户端增加对应功能。

## 播放速度

客户端决定速度，不读取本仓库 `animation.json` 中的自定义时长。当前原生待机六帧时长为 **1680、660、660、840、840、1920 毫秒**，一轮 6.6 秒。单张静态图集无法把这些停留时间变成视频级的连续动画。其余行较快，例如悬停回应五帧一轮约 0.84 秒、左右移动八帧一轮约 1.06 秒。

`animation.json` 的 `durationMs` 供独立应用使用；原生预览应使用明确记录的 `nativeDurationMs`，避免用加速预览误示实际效果。

v2 的附加行用于鼠标方向追视；当前客户端会在一些状态直接固定到追视帧，因此升级 v2 不等于增加可自由播放的表情动画。

## 与参考视频的关系

参考视频约 6.4–7.3 秒可以逐帧看到：脚底基本固定，换立绘后先纵向拉长、横向收窄，再压扁回弹，约 0.8 秒恢复。平时主要是约 2–3% 的慢速呼吸缩放。这里采用固定脚底的立绘变换，保留原始角色图片，不把整窗随机漂移当作视频中的呼吸动作。

## 动态 WebP 实验

当前本地加载链会保留 WebP 文件原始字节，技术上可尝试在整张图集中内嵌时间动画。但这不是已确认的稳定素材接口：内存占用、宿主的减少动态效果选项、动画时间线同步和云端迁移都需要另行验证。实验文件必须与普通静态图集区分，不能仅凭浏览器预览宣称已通过 Codex 实机测试。
