# running-right: 固定脚底的立绘弹性

当前使用 `pet/sprites/smile.png`，以脚底 y=202 为锚点渲染八个缩放帧，不调用图片生成。

- 纵向比例：`[1,1.10,1.035,0.96,1.018,0.996,1,1]`。
- 横向比例为纵向比例的轻微反向补偿，参数在 `video-motion.json` 中记录。
- 与左向行像素相同；不镜像、不改人物面向、不做腿部跑动。
- 窗口平移由 Codex 控制，图集只提供站姿压缩、拉伸及回弹。
- 由 `codex/tools/build_video_style.py` 从未修改的原始 PNG 可复现。
