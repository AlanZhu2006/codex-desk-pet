## Codex 动画

逐帧分析参考视频约 6.4–7.3 秒，观察到表情切换后整张立绘先纵向拉长、横向收窄，再压扁并恢复，脚底基本不动。平时为约 2–3% 的慢速呼吸缩放；不能将背景镜头平移当作桌宠主动随机游走。

本版通过 [素材编译器](tools/build_video_style.py) 将原始立绘渲染到 192×208 的固定单格，脚底基线为 y=202，正常高度 170。悬停回应的纵向比例依次为 `[1.13,0.96,1.02,0.995,1]`，横向依次为 `[0.90,1.05,0.985,1.005,1]`。左右拖动保持相同站姿、相同面向，不做腿部跑动，真实窗口位移由宿主控制。

本次没有新绘制人物或调用图片生成；只渲染已有 PNG 的几何变换并拼装图集。完整原图哈希、变换参数、视频量测与时长见 [video-motion.json](video-motion.json)。

图集采用 Codex 原生 v1 格式，9 行共 57 帧；行数、帧数与时长记录见 [animation.json](animation.json)，校验见 [validation.json](validation.json)。原生待机只有六个固定帧、实际循环6.6秒，因此普通图集不能达到原视频连续变形的帧率。预览采用原生时长，不以加速播放替代实机效果。

[prompts](prompts/) 保留早期生成实验的记录；`crying-cutout.md` 仍对应本版大哭原图。其余旧动作提示词不代表当前 Codex 图集的制作过程。macOS 0.4 版使用同一批高分辨率原图、同一170px高度与y=202脚底构图，在绘制层连续完成呼吸与切换弹性，避免再次放大预缩小的图集或叠加两遍变形。

## macOS 的 Codex 鲜亮风格

macOS 0.6 根据用户的两只角色对照图，恢复使用早期 Codex 生成图集作为默认材质。对照图上方的看书姿态对应早期图集第8行、第5列；下方则为作者原始 `smile.png`，两者的画法和色彩本就不同。

`macos/Resources/Atlas.png` 从早期已完成的 v1 WebP 图集无损转换，保留完全相同的RGBA像素，并标记标准sRGB。它与当前 `codex/claude-sunflower/spritesheet.webp` 的原立绘视频式素材包是独立资源。早期生成动作的来源、角色参考与历史提示词仍保留在本仓库记录中，本次没有重新生成或重绘人物。

Mac中的待机、打字、看书、大哭、招呼、庆祝、等候站姿七组直接复用对应原帧，不额外套提亮gamma，并使用与Codex相近的清晰像素采样。0.6版的其余四张原始表情通过运行时色彩调整靠近该配色；0.7版已用下述独立生成的动画替换默认鲜亮风格中的这四张。原立绘显示选项仍可使用原始素材。

## macOS 0.7：统一四种补充表情

2026-11-01使用内置 imagegen，依据经典 Codex 图集中的微笑、睁眼站姿和看书画面，生成眯眼笑、慌张、委屈、石化四组各六帧的透明背景动画。作者原始四种表情仅作为神情和手势参考；新画面为AI生成的风格延续，不是作者原始素材，也不是仅对原图提亮或整体缩放。

- 眯眼笑：微笑、抬手掩嘴、张嘴笑、双手收拢、放松并回到起始姿态。
- 慌张：睁大眼、抬起双手、慌乱摆手、闭眼、放下手并回到起始姿态。
- 委屈：侧目、低头、眨眼、害羞轻歪头、收手并回到起始姿态。
- 石化：抱书僵住、眼睑与手指变化、微小歪头和局部石纹；保留橙发和鲜亮服装，没有整体灰化。

四份完整提示词保存在 [prompts/unified-expressions](prompts/unified-expressions/)。生成原图、三张经典参考和可复现的图集打包脚本保存在 [macos/artwork/unified-expressions](../macos/artwork/unified-expressions/)。背景中不可见的RGB不被当作人物颜色；打包保留生成图的透明度，不通过去白底或色键重绘边缘。

补充图集为 `macos/Resources/CodexExtraExpressions.png`，sRGB RGBA，1536×832、8列×4行、单格192×208。每行前六格有效、后两格透明，行序为眯眼笑、慌张、委屈、石化。人物使用每组共享比例和统一脚底线；原有七组图帧不变。动画时长分别为2180、1320、2700、3420毫秒，包含各自不同的停顿和动作节奏。默认鲜亮风格的11种表情均有多张逐帧画面；暂停和系统减少动态效果仍会停止播放。
